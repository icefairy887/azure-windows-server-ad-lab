# Azure Active Directory Lab

Hands-on Windows Server and Active Directory lab deployed in Microsoft Azure using PowerShell.

## Planned Environment

- Azure region: Central US
- Resource group: `rg-adlab`
- Virtual network: `vnet-adlab`
- Subnet: `snet-ad`
- Domain controller: `DC01`
- Private IP: `10.10.1.4`
- Planned domain: `corp.brookelab.test`

## Project Goal

Build and document an Active Directory environment from the infrastructure layer up, including Azure networking, Windows Server, AD DS, DNS, users, groups, OUs, Group Policy, and PowerShell automation.

## Status

Infrastructure setup in progress.
