# Repository Context

## Objective

Build a small, explainable Azure Active Directory portfolio lab through manually reviewed PowerShell stages.

## Current boundary

The code and documentation are prepared. Infrastructure deployment has not been authorized as part of this repository-completion task.

## Review priorities

1. PowerShell syntax and idempotency
2. Secret and personal-data handling
3. Azure cost and exposure risk
4. Correct dependency order
5. Clear documentation for a junior administrator
6. Agreement between code, config, and docs

## Known constraints

- Azure for Students has region restrictions.
- `centralus` is the planned allowed region.
- Cloud Shell can have low memory.
- RDP may be opened only to one run-time-supplied source IPv4 address.
- The lab uses one DC and is not a production architecture.
