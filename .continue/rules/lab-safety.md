# Azure AD lab safety rule

This repository is an un-deployed learning lab unless the user explicitly says otherwise.

- Do not execute Azure, Windows Server, or Active Directory scripts.
- Do not add or expose credentials, real identities, subscription IDs, tenant IDs, or public home IP addresses.
- Restrict analysis to repository content and offline validation by default.
- Use the planned values in `config/lab.config.psd1`.
- Explain any state-changing suggestion before the user runs it.
